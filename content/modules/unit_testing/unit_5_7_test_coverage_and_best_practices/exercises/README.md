# Unit 5.7 Exercises: Test Coverage and Testing Best Practices

## Overview
These exercises test your mastery of:
- Achieving comprehensive statement and branch coverage
- Testing complex compound Boolean predicates
- Eradicating false confidence through rigorous assertions
- Testing clinical audit logs and boundary conditions

## How to Run the Exercises

### Run Starter Code (Student Verification):
```bash
pytest content/modules/unit_testing/unit_5_7_test_coverage_and_best_practices/exercises/unit_5_7_test_coverage_and_best_practices_exercises.py -v
```

### Run Reference Solution:
```bash
pytest content/modules/unit_testing/unit_5_7_test_coverage_and_best_practices/exercises/solutions/unit_5_7_test_coverage_and_best_practices_exercises.py -v
```

### Run with Coverage:
```bash
pytest content/modules/unit_testing/unit_5_7_test_coverage_and_best_practices/exercises/solutions/unit_5_7_test_coverage_and_best_practices_exercises.py --cov=content/modules/unit_testing/unit_5_7_test_coverage_and_best_practices/exercises/solutions --cov-branch --cov-report=term-missing
```
