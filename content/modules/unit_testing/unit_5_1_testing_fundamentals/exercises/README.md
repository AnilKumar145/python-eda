# Unit 5.1 Exercises: Testing Fundamentals

## Overview
These exercises test your mastery of testing foundations: the Arrange-Act-Assert (AAA) pattern, test isolation, semantic test naming, and deterministic assertion writing.

## How to Run the Exercises

### Run Starter Code (Student Verification):
```bash
pytest content/modules/unit_testing/unit_5_1_testing_fundamentals/exercises/unit_5_1_testing_fundamentals_exercises.py -v
```

### Run Reference Solution:
```bash
pytest content/modules/unit_testing/unit_5_1_testing_fundamentals/exercises/solutions/unit_5_1_testing_fundamentals_exercises.py -v
```
