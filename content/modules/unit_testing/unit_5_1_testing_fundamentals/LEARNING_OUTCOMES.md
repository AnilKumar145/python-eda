# Learning Outcomes: Unit 5.1 - Testing Fundamentals

By the end of this unit, you will be able to:

1. **Deconstruct the Test Pyramid**: Differentiate between unit tests, integration tests, and end-to-end (E2E) tests in terms of execution speed, cost, and reliability.
2. **Apply the Arrange-Act-Assert (AAA) Pattern**: Structure clean, readable test cases with distinct setup (Arrange), execution (Act), and verification (Assert) phases.
3. **Execute the TDD Cycle**: Apply the Test-Driven Development workflow (Red $\to$ Green $\to$ Refactor) to write verified production code.
4. **Ensure Strict Test Isolation**: Write independent test cases that do not share mutable global state, ensuring zero order-of-execution dependencies.
5. **Enforce Semantic Test Naming**: Structure descriptive test function names using industry patterns such as `test_<action>_<condition>_<expected_result>()`.
