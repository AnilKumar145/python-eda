# Unit 5.4 Exercises: Mocking and Isolation

## Overview
These exercises test your mastery of test doubles, `unittest.mock.Mock`, `MagicMock`, behavior configuration (`return_value`, `side_effect`), interaction verification, and patching external network collaborators.

## How to Run the Exercises

### Run Starter Code (Student Verification):
```bash
pytest content/modules/unit_testing/unit_5_4_mocking_and_isolation/exercises/unit_5_4_mocking_and_isolation_exercises.py -v
```

### Run Reference Solution:
```bash
pytest content/modules/unit_testing/unit_5_4_mocking_and_isolation/exercises/solutions/unit_5_4_mocking_and_isolation_exercises.py -v
```
