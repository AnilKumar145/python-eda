# Unit 5.3 Exercises: Fixtures and Test Data

## Overview
These exercises test your mastery of pytest fixtures, yield-based teardown management, parameterized boundary testing matrices with `@pytest.mark.parametrize`, and filesystem isolation with `tmp_path`.

## How to Run the Exercises

### Run Starter Code (Student Verification):
```bash
pytest content/modules/unit_testing/unit_5_3_fixtures_and_test_data/exercises/unit_5_3_fixtures_and_test_data_exercises.py -v
```

### Run Reference Solution:
```bash
pytest content/modules/unit_testing/unit_5_3_fixtures_and_test_data/exercises/solutions/unit_5_3_fixtures_and_test_data_exercises.py -v
```
