# Unit 5.5 Exercises: Exceptions and Edge Cases

## Overview
These exercises test your mastery of exception testing with `pytest.raises`, message regex validation, custom exception payload assertions, boundary value analysis (BVA), and invalid edge case rejection.

## How to Run the Exercises

### Run Starter Code (Student Verification):
```bash
pytest content/modules/unit_testing/unit_5_5_exceptions_and_edge_cases/exercises/unit_5_5_exceptions_and_edge_cases_exercises.py -v
```

### Run Reference Solution:
```bash
pytest content/modules/unit_testing/unit_5_5_exceptions_and_edge_cases/exercises/solutions/unit_5_5_exceptions_and_edge_cases_exercises.py -v
```
