# Unit 4.3 Exercises: Advanced ORM Features

## Overview
These exercises reinforce many-to-many relationship modeling via association tables, hybrid properties with SQL expressions, and eager loading optimization via `selectinload`.

## Running the Exercises

### Student Starter:
```bash
python content/modules/database_part_2/unit_4_3_advanced_orm_features/exercises/unit_4_3_advanced_orm_features_exercises.py
```

### Reference Solution:
```bash
python content/modules/database_part_2/unit_4_3_advanced_orm_features/exercises/solutions/unit_4_3_advanced_orm_features_exercises.py
```
