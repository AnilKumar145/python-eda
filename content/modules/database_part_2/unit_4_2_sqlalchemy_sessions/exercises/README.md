# Unit 4.2 Exercises: SQLAlchemy Sessions

## Overview
These exercises reinforce session lifecycle states, adding, committing, updating, deleting entities, and querying with modern SQLAlchemy 2.0 `select()` and `session.scalars()`.

## Running the Exercises

### Student Starter:
```bash
python content/modules/database_part_2/unit_4_2_sqlalchemy_sessions/exercises/unit_4_2_sqlalchemy_sessions_exercises.py
```

### Reference Solution:
```bash
python content/modules/database_part_2/unit_4_2_sqlalchemy_sessions/exercises/solutions/unit_4_2_sqlalchemy_sessions_exercises.py
```
