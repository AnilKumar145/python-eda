# Unit 4.1 Exercises: ORM Fundamentals

## Overview
These exercises reinforce modern SQLAlchemy 2.0 declarative modeling, column definition with type annotations, foreign key constraints, and 1-to-many relationship navigation.

## Running the Exercises

### Student Starter:
```bash
python content/modules/database_part_2/unit_4_1_orm_fundamentals/exercises/unit_4_1_orm_fundamentals_exercises.py
```

### Reference Solution:
```bash
python content/modules/database_part_2/unit_4_1_orm_fundamentals/exercises/solutions/unit_4_1_orm_fundamentals_exercises.py
```
