# Exercises: Unit 3.1 - Database Fundamentals

Practice relational schema definition, constraints, CRUD queries, foreign key enforcement, and query plan index inspection in Python.

## Exercises Overview:
1. **Exercise 1: Clinic Schema Builder**: Write a function that creates a relational schema for `clinics` and `doctors` with foreign keys and checks.
2. **Exercise 2: Parameterized Patient Filter**: Query patients matching a specific department with ordering.
3. **Exercise 3: Foreign Key Constraint Guard**: Verify that inserting an orphan appointment raises an `IntegrityError`.
4. **Exercise 4: Index Creator & Query Plan**: Create a B-Tree index on a medical record column and verify the query plan uses the index.
