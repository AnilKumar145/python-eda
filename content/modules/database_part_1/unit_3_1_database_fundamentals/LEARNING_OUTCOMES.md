# Learning Outcomes: Unit 3.1 - Database Fundamentals

By the end of this unit, you will be able to:
1. **Model Relational Data**: Define entities, primary keys (PK), composite keys, and foreign keys (FK) enforcing referential integrity.
2. **Execute Core SQL DML & DDL**: Write performant `CREATE TABLE`, `INSERT`, `SELECT` with filtering (`WHERE`, `ORDER BY`, `LIMIT`), `UPDATE`, and `DELETE` queries.
3. **Analyze Database Indexing**: Explain how B-Tree indexes speed up lookups from $O(N)$ full table scans to $O(\log N)$ tree traversals, and describe write performance trade-offs.
4. **Compare RDBMS Engines**: Evaluate trade-offs between embedded file engines (SQLite) and enterprise client-server engines (PostgreSQL, MySQL) for product architectures.
5. **Establish Python Database Connectivity**: Understand the role of Python client drivers and the standard database interface layer.
