# Unit 2.5 Exercises: Concurrent Programming Patterns

Master foundational concurrency patterns in isolation:
1. **Exercise 1: Bounded Task Pipeline (Producer–Consumer)** - Coordinate a bounded queue with poison-pill shutdown and backpressure.
2. **Exercise 2: Fan-Out / Fan-In Map-Reduce** - Scatter numerical workloads across workers and gather aggregated statistics.
3. **Exercise 3: Safe Multi-Resource Lock Hierarchy** - Acquire two contested resource locks without risking circular wait deadlock.

### Running Exercises
Execute the starter exercises:
```bash
python exercises/unit_2_5_concurrent_programming_patterns_exercises.py
```

Check the solution file:
```bash
python exercises/solutions/unit_2_5_concurrent_programming_patterns_solutions.py
```
